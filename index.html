Everything you open a database client for

Connect, query, browse and edit, all without leaving one window.

Three engines, native drivers

PostgreSQL, MySQL/MariaDB and SQLite through drivers written in pure Swift. TLS is supported, including verify-full.

Tunnels built in

Connect through SSH or AWS Systems Manager Session Manager to databases with no public access. SSO profiles work.

A real SQL editor

Tabs, syntax highlighting, completion, a formatter, history, Explain Plan, and cancel for long-running queries.

Edit with a safety net

Edit rows inline. DELeaver shows you the SQL and runs every change in a transaction once you confirm it.

Export and import

Sort, filter and page through typed results. Export to CSV or JSON, and preview a CSV before you import it.

Secrets stay secret

Passwords live in the macOS Keychain. Profiles never store them, and the app never reads your AWS credentials.

Build it in a minute

You need Swift 6 or later. It has no third-party packages.

git clone https://github.com/delfrinandopranata/DELeaver.git
cd DELeaver
scripts/make-app.sh && open build/DELeaver.app
